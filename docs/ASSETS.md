# Asset provenance

Every asset in this repository is original to the Yukariko project.

| Asset | Origin |
|---|---|
| `internal/ui/static/style.css` | Hand-written for Yukariko. The palette (deep navy `#14213d`, ivory `#f6f1e7`, lapis `#2e5ea8`, restrained gold `#b99a45`) and the archive/chapel mood are original design decisions documented in the issue thread. No frameworks, resets, or third-party stylesheets were copied or derived. |
| `internal/ui/templates/*.html` | Hand-written Go `html/template` files. No third-party layouts or component libraries. |
| No images, fonts, logos, or audio | The dashboard is typography and CSS only. In particular there are **no** Mai-HiME/Mai-Otome (or any third-party) assets, characters, logos, or marks: the Yukariko name and its presentation are original to this project. |

Any future asset must be added to this inventory with its origin and license,
or replaced by an original work.
